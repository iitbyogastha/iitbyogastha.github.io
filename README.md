# 🧘 IITB Yogastha Website

Welcome to the official repository for **IITB Yogastha** — the yoga community of IIT Bombay. This website serves as a central hub for events, initiatives, and information related to yoga activities conducted on campus.

---

## 🌐 Live Website

🔗 https://iitbyogastha.in

---

## 📌 About Yogastha

**Yogastha** is a student-driven initiative at IIT Bombay focused on promoting physical, mental, and spiritual well-being through yoga.

We organize:

* 🧘 Regular yoga sessions
* 🌍 International Yoga Day events
* 🏫 Workshops and awareness programs
* 🤝 Collaborations with wellness communities

---

## 🚀 Features of the Website

* 📄 Informational pages (About Us, Events, Team)
* 📸 Event galleries (IDY 2022, 2023, etc.)
* 📅 Updates on upcoming sessions
* 🎨 Clean and responsive UI
* ⚡ Fast static hosting via GitHub Pages

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling (Bootstrap + custom styles)
* **JavaScript** – Interactivity
* **GitHub Pages** – Hosting

---

## ⚙️ Deployment

This site is deployed using **GitHub Pages**.

### Steps:

1. Push changes to the `main` branch
2. GitHub automatically rebuilds and deploys
3. Custom domain is linked via DNS

---

## 🌍 Custom Domain

The website uses a custom domain:
👉 `iitbyogastha.in`

Configured using:

* GitHub Pages settings
* DNS records (A/CNAME)
